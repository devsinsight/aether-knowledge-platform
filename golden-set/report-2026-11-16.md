# Retrieval quality report: after the Miro reader, cross-source links and the chunker fix (2026-11-16)

**State: draft.** Written by an AI agent from the `eval` command output; pending validation. Same golden set ([`aether.yaml`](aether.yaml), 34 questions) and setup as the [baseline](report-2026-11-13.md).

## What changed in the corpus since the baseline

- **Miro reader:** 9 boards, 39 frames, 51 chunks, all in state `draft`, so out of the default filter.
- **Cross-source links:** 9 pages that embed a board got one line per embed (`Embedded board: <title>`).
- **Chunker fix:** Docling dropped everything before the first heading on pages without an `<h1>`. That affected 28 of 78 pages, among them the status tables of ADR-006 to ADR-019. The title is now added as the `<h1>`. The full ingest re-embedded 161 of 477 chunks and the collection went from 501 to 528 points.

- "How do I run the backend on my machine?" moved down to second.

**With drafts:** the Miro frames did not push any expected item out of the top 5.

## Reading

There is no regression. The baseline's caveat still holds: the questions reuse the words of the pages, so these numbers are optimistic.
